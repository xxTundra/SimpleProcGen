Intro

What TTRPG Tools is

TTRPG Tools is a local web app for tabletop roleplaying. The main window has a roll bar at the top — the Normal, Advantage, and Disadvantage buttons next to an expression field — and a tab bar below it: Macros, Tables, Generators, Logic, and Files. Everything runs in your browser, and everything the app stores lives in the app folder as plain JSON files.

The modules

The app's data lives in plain JSON files in the app folder — the macros in dice-macros/, the tables in tables/, the generators in generators/, and the logic operations in logic-ops/ — and the Files tab lists, uploads, downloads, and deletes them.

How the help pages connect

Each feature has its own page — Dice, Macros, Tables, Generators, and Logic — and the sidebar on every page links to them, with prev and next buttons at the bottom stepping through the pages in order. The Help button in each of the four features — the roll panel, Tables, Generators, and Logic — opens the matching page in a new tab. The Macros tab has no Help button of its own, so its page is reached via the sidebar.
